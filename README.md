# Fuad & Nisan · fnwedding.com

The wedding website for **Fuad & Nisan** — a Somali-Yemeni wedding in Nairobi, Kenya, 19–23 December 2026.
*Yesterday, Today & Tomorrow.*

**Live:** https://fnwedding.com

## What's here
- **Home** — cinematic opening: two hands meet, a heart, then five flight paths (Italy, Canada, UAE, Egypt, Greece) converge on Nairobi; countdown; welcome letter; the Brunfelsia theme.
- **Our Story**, **Celebrations** (Henna · Nikah · Zifaf), **Travel & Stay**, **Guest Info** (FAQ), **Gallery**, **Honeymoon Fund**, **RSVP**.
- **/admin/** — private guest management for the couple: per-event counts, search, CSV export, honeymoon notes.

## Stack
Plain HTML/CSS/JS generated by a tiny Node build script (`src/build.mjs`, no dependencies), hosted on GitHub Pages.
RSVPs are stored in Supabase (Postgres + Row Level Security) — see `supabase/schema.sql`.
